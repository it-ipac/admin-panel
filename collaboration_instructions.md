# Collaboration Instructions

- All work must be done in a feature branch.
- Feature branches must be merged into `dev` first.
- `dev` is the preview/testing branch: https://ipac-admin-dev.vercel.app/
- Test and verify all changes on `dev` before production.
- After a feature is finished and tested, always open a pull request from `dev` to `main` to stage the changes for production.
- Only verified changes from `dev` may be merged into `main`.
- `main` is the production branch: https://ipac-admin.vercel.app/
- Never merge a feature branch directly into `main`.
