# Branch Naming

Use **lowercase** branch names and separate words with **hyphens**.

## New Feature

**Format**

`feat/feature-name`

**Example**

`feat/report-select-all`

## Bug Fix

**Format**

`fix/problem-name`

**Example**

`fix/report-date-filter`

## Hotfix

**Format**

`hotfix/problem-name`

Use only for urgent production fixes.

## Documentation

**Format**

`docs/topic-name`

**Example**

`docs/collaboration-rules`

## Rules

- Do not work directly on `dev` or `main` for features or fixes.
- Create a dedicated branch using the naming rules above.
- Keep branch names short and clear.
